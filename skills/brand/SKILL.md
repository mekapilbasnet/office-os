# Brand

Brand identity, voice, messaging, asset management, and consistency frameworks.

## When to Use

- Brand voice definition and content tone guidance
- Visual identity standards and style guide development
- Messaging framework creation
- Brand consistency review and audit
- Asset organization, naming, and approval
- Color palette management and typography specs

## Quick Start

Scripts are run by full path (`~/.claude/skills/brand/scripts/...`), so the current directory does not matter; `sync-brand-to-tokens.cjs` reads and writes the project in the current directory, so run that one from the project root.

**Windows:** in cmd or PowerShell `~` may not expand; use `%USERPROFILE%\.claude\skills\brand\scripts\...` (cmd) or `$HOME\.claude\skills\brand\scripts\...` (PowerShell) instead of `~/.claude/skills/brand/scripts/...`.

**Inject brand context into prompts:**
```bash
node ~/.claude/skills/brand/scripts/inject-brand-context.cjs
node ~/.claude/skills/brand/scripts/inject-brand-context.cjs --json
```

**Validate an asset** (naming, format, file size, pixel dimensions, manifest entry; report only, it never renames files):
```bash
node ~/.claude/skills/brand/scripts/validate-asset.cjs <asset-path>
```

**Show the brand palette / compare an image's colors against it:**
```bash
node ~/.claude/skills/brand/scripts/extract-colors.cjs --palette
node ~/.claude/skills/brand/scripts/extract-colors.cjs <image-path>   # SVG and 8-bit PNG only; reports on-brand vs off-brand colors
```
For JPEG/WebP the script prints an ImageMagick command instead of guessing.

## Brand Sync Workflow

```bash
# 1. Edit docs/brand-guidelines.md (or use /brand update)
# 2. Sync to design tokens (run from the project root; also writes the CSS)
node ~/.claude/skills/brand/scripts/sync-brand-to-tokens.cjs
# 3. Verify
node ~/.claude/skills/brand/scripts/inject-brand-context.cjs --json | head -20
```

**Files synced:**
- `docs/brand-guidelines.md` → Source of truth
- `assets/design-tokens.json` → Token definitions
- `assets/design-tokens.css` → CSS variables, generated by the same script (no other tool needed)

## Subcommands

| Subcommand | Description | Reference |
|------------|-------------|-----------|
| `update` | Update brand identity and sync to design tokens + CSS | `references/update.md` |
| `review` | Audit existing work against the brand guidelines | Inline below |
| `create` | Create a new brand guideline file from the starter template | Inline below |

### `review` (inline)

1. Read `docs/brand-guidelines.md` (or the path given); run `node ~/.claude/skills/brand/scripts/inject-brand-context.cjs --json` to load colors, fonts and voice.
2. Check the target (page, doc or asset) with `references/consistency-checklist.md`; run `node ~/.claude/skills/brand/scripts/validate-asset.cjs` and `node ~/.claude/skills/brand/scripts/extract-colors.cjs` on image assets.
3. Report findings as pass / fix lists per area (color, typography, logo, voice) with the exact rule violated.

### `create` (inline)

1. Ask the user (`AskUserQuestion`) for brand name, mood, primary / secondary / accent colors, fonts and voice.
2. Copy `templates/brand-guidelines-starter.md` to `docs/brand-guidelines.md` and fill it in (see `references/brand-guideline-template.md`); title it `# <Brand Name> Brand Guidelines`.
3. Run `node ~/.claude/skills/brand/scripts/sync-brand-to-tokens.cjs` to generate the tokens and CSS.
