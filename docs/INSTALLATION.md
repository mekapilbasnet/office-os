# Installation Guide

## Linux / macOS / WSL

```bash
./install.sh
./install.sh --apply
./verify.sh
```

## Windows PowerShell

```powershell
.\install.ps1
.\install.ps1 --apply
.\verify.ps1
```

## Notes

- Dynamic Routing is **enabled by default** after installation.
- Restart Claude Code after install or after switching routing on or off.
- Use `/office-os` as the main skill command.
